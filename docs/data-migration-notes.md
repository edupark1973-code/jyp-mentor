# 자료 통합 조사 메모

## 원본 구조

- 스타트업 통합문서: 22개 시트. 가장 큰 `kict` 시트는 약 9,578행, `2015~2023 스타트업`은 약 4,908행이다. 집계에는 제목과 빈 서식 행이 포함될 수 있다.
- 강사·멘토 통합문서: `피어멘토`, `전문 멘토`, `IR심사`, `멘토자격` 네 시트다.
- 외주업체 통합문서: `외주용역업체목록`과 시스템 생성 `App Metadata` 시트가 있다.

## 이관 시 확인 사항

- `kict전담멘티`, `kict`, 협동조합 관련 시트, `모두의창업` 등은 첫 행이 일반적인 열 제목이 아니다. 시트별 제목 행과 데이터 시작 행을 확인해야 한다.
- `멘토자격`은 사용자 요청에 따라 이관 대상에서 제외한다.
- 외주업체 시트는 첫 행이 설명이고 두 번째 행에 열 제목이 있다. `App Metadata`는 업체 명단이 아니다.
- 원본 셀 값과 시트명, 행 번호를 보존하고 공통 필드 매핑은 별도로 관리한다. 이름이 같다는 이유로 자동 병합하지 않는다.
- 확인이 필요한 셀, 제목 행과 데이터가 혼재된 행, 자격 기준 등은 검토 대상으로 남겨야 한다.
- 외부 공유 시 전화번호, 이메일 등은 기본 제외하고 선택한 필드만 별도로 제공한다.
